# カテゴリーアイコン マル案

新発売ポチなどの一覧チップ用、食べ物カテゴリーアイコン21種のマル案。
モルのA案（輪郭線なしのフラット多色）・B案（太い輪郭線のイラスト風）と方向を変え、
**輪郭線を使わず、ゆるやかなグラデーションとハイライトで立体感を出す「クレイ風」**にした。

## 設計の約束

- SVG、viewBox は 0 0 48 48。ファイル名は指定どおり（onigiri.svg など21種）。
- 各アイコンに、主素材のグラデーション（上を明るく）、左上の白いハイライト、
  足元の柔らかい影を共通で入れ、輪郭線なしでも形が立つようにした。
- 一覧チップでの表示サイズ（18〜24px）を前提に、48px・24px・20px で
  明るい背景（#fdf8f4）と暗い背景（#231b17）の両方に並べて判読を確認済み。
- グラデーションやクリップの id はファイルごとに接頭辞を付けて一意にしてある
  （例：oni-rice、bur-bun）。1ページに複数アイコンをインラインで並べても衝突しない。
- 既存のアイコン集・絵文字は参照せず、すべてオリジナルで描いた。

## 見分けの工夫（モル初版で見分けにくかったもの）

- 丼：青い丼鉢＋白いごはんの山＋カツの茶色を3切れ載せ、鉢の形で読ませる。
- 寿司：下駄の上にサーモン（白い筋入り）とマグロの2貫を並べた。
- サンドイッチ：三角の断面に、レタスの波・トマト・チーズの層を入れた。
- パスタ：黄色い麺の山の中央に赤いソースを置き、色の対比で読ませる。
- 中華まん：白い丸に頂点のひだ寄せを描き、紙の台を敷いた。
- カレー：楕円の皿に白いごはんと茶色いルーを半々にし、具の角を2つ置いた。
- 揚げ物（惣菜）：唐揚げの塊を4つ重ね、レモンのくさびとパセリを添えた。
